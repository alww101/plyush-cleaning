# Плюш · набор инструментов и источников

Этот файл фиксирует, что было подключено к MVP, что использовано при сборке и какие пункты из рабочего списка требуют отдельного подключения.

## Подключено и применено

- **Figma MCP** — редактируемый файл экранов: `https://www.figma.com/design/5fA1EGBl8dAWOc5FwlPHyX`. Главный экран, выбор мебели, корзина и кабинет собираются слоями Figma, а не одним скриншотом.
- **Blender / bpy** — двенадцать оригинальных моделей и вариантов: `public/models/*.glb`, исходники `assets-source/*.blend`, скрипт повторной сборки `assets-source/build_models.py`.
- **frontend-design** — визуальное направление «Плюш»: молочный фон, лавандовый акцент, Manrope, крупная типографика, 3D-предмет как главный фокус.
- **React + Next.js + React Three Fiber + Drei** — интерактивная сцена с поворотом, тенями, reduced motion, fallback-постерами и ограничением DPR.
- **Three.js loaders / materials / lighting** — GLTFLoader через `useGLTF`, физически правдоподобные материалы, направленный свет и `ContactShadows`.
- **React / Next.js performance** — динамическая загрузка сцены, `frameloop="demand"`, ограниченный DPR, лёгкие GLB и WebP-постеры.
- **Vercel / Sites workflow** — приложение подготовлено как Next.js-проект с `build`, `.env.example`, server-side секретами и явным списком ограничений публикации.
- **Context7 / официальная документация** — совместимость Next.js 16, React 19, R3F 9, PGlite и `sharp` сверена по первичным источникам.

## Лицензии и модели

Производственные модели сделаны в Blender специально для этого проекта и передаются с `.blend`. Архив Kenney Furniture Kit сохранён как открытый альтернативный источник и отдельно отмечен в `assets-source/ASSETS.md`; он не смешан с производственными мешами.

## Что не является автоматически установленным пакетом

Названия **apple-design**, **web-design-guidelines**, **react-best-practices**, **threejs-loaders**, **threejs-materials**, **threejs-lighting**, **Innerscene Free Parts library** и **Условия Innerscene** из скриншотов сохранены как список внешних материалов. Для Innerscene добавлены прямые ссылки: [Free Parts Library](https://www.innerscene.com/tools/library/terms) и [условия 3D Viewer](https://www.innerscene.com/tools/3d-viewer/terms). Чужие детали в production-бандл не включены: библиотека содержит пользовательские и публичные модели, поэтому права нужно проверять для каждой модели. Их роль закрыта локальными правилами проекта, официальной документацией и собственными моделями с лицензией.

## Перед передачей компании

Нужно настроить `DATABASE_URL`, `APP_ORIGIN`, рабочие контакты, юридические сведения и пароль владельца. Для публикации на serverless-платформе нужен PostgreSQL и объектное хранилище/адаптер для фото; локальная PGlite-база предназначена только для демо и разработки. Платёж, расписание мастеров, CRM, роли и уведомления остаются отдельными расширениями.
